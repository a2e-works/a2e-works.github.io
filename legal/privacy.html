A2E Works(以下「当方」)は、本サイトおよび当方のソフトウェア(以下「本製品」)で扱う情報を、次のとおり取り扱います。

1. 本製品で扱うデータ

電帳DIY：読み込まれた書類のデータ、台帳、作業記録は、利用者のパソコンのブラウザ内および利用者が指定したフォルダにのみ保存されます。当方のサーバーには送信されません。

IDおそうじ：読み込んだメールは、利用者のパソコンのブラウザの中だけで処理し、当方のサーバーには送信しません。製品版では、見つかったサービスの一覧や対応の記録(サービス名、ドメイン、届いた宛先、日付、件名の一部など)を、利用者のブラウザ内にのみ保存します。無料デモ版は記録を保存しません。保存された記録は、画面の「すべて消して初期状態に戻す」で消せます。パスワードを入力する場所はなく、パスワードを取得・保存することはありません。

2. 通信が発生する場面

電帳DIY：(1) 読み取り用の部品を最初に取得するとき、(2) アプリを最新の状態にするとき。いずれも、利用者の書類データは送信されません。

IDおそうじ

  • Thunderbird・Outlookのデータファイル・書き出したメールファイルを読み込む場合、外部との通信は行いません(ページの設定で通信を止めており、画面の「通信の確認」で確かめられます)。
  • Gmail版を使う場合、利用者がGoogleにログインして許可したうえで、Googleとだけ通信します。読み取り専用の許可で、差出人・件名・日付と本文の冒頭の数行を読み、その処理は利用者のブラウザの中だけで行います。Googleから受け取った情報を当方が受け取ったり、第三者に提供したりすることはありません。Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含みます)に従います。
  • 画面の「公式サイト」「検索」などのリンクを利用者が押した場合、そのサイトや検索サービス(Google)へ移動します。検索の場合、サービス名を含む検索語が検索サービスに送られます。当方に情報が送られることはありません。

3. Googleユーザーデータの取り扱い（IDおそうじ Gmail版）

※ IDおそうじのGmail版（Googleにログインして直接読み込む版）は、現在準備中で、提供していません。提供を始める場合は、この項目の内容に沿って取り扱います。

IDおそうじのGmail版が、Google API（Gmail API）から受け取るデータ（以下「Googleユーザーデータ」）の取り扱いは、次のとおりです。

(1) アクセスするデータ

  • 許可の範囲は、読み取り専用の https://www.googleapis.com/auth/gmail.readonly だけです。
  • アカウントのメールアドレス（どのアカウントを読み込んだかの表示に使います）。
  • 迷惑メール・送信済み・下書き・チャットを除くメールの一覧（メールのID）。
  • 各メールのヘッダーの一部（From、To、Subject、Date、Message-ID、In-Reply-To、Delivered-To、Authentication-Results、List-Unsubscribe、List-Unsubscribe-Post、Precedence）と、Gmailが用意する本文冒頭の短い抜粋（snippet）。
  • メール本文の全体や添付ファイルは取得しません。メールの変更・削除・送信・ラベル付けは一切行いません。

(2) データの使い方

  • 差出人のドメインごとにメールをまとめ、利用者が登録したことのあるサービス（登録・ログイン・パスワード・注文などのメール）を見つけるためだけに使います。
  • 情報漏洩のお知らせが届いていたサービスを見分けて、利用者に示します。
  • 見つかったサービスごとに、公式サイト・パスワード変更・退会などの入口を案内します。
  • 集計したデータ（サービス名、ドメイン、届いた宛先、日付、最近の件名など）も、利用者の画面に表示するためだけに使います。
  • 広告（ターゲティング広告を含む）、信用・融資の判断、AI・機械学習モデルの開発・学習には使いません。

(3) データの共有・受け渡し

  • Googleユーザーデータ（そのままのデータも、集計・匿名化したデータも）を、当方が受け取ることはなく、第三者（広告主、データブローカー、AIサービスを含む）に提供・販売・移転することもありません。
  • 通信は、利用者のブラウザとGoogle（ログインとGmail API）の間だけで行います。

(4) データの保護

  • すべての処理は、利用者のパソコンのブラウザの中だけで行います。当方はサーバーを持たず、Googleユーザーデータがサーバーに送られることはありません。
  • ページの設定（Content-Security-Policy）で、Googleのログインと Gmail API 以外への通信を止めています。通信はすべて暗号化（HTTPS）されます。
  • アクセストークンはブラウザのメモリにだけ置き、ページを閉じると破棄します。保存はしません。

(5) 保存と削除

  • 当方のサーバーには何も保存しません。
  • 利用者のブラウザには、追加したアカウントのメールアドレスだけを保存します。画面の「外す」で消せます。無料デモ版は、読み込んだ結果を保存しません（ページを閉じると消えます）。製品版は、集計した結果を利用者のブラウザの中にだけ保存し、画面の「すべて消して初期状態に戻す」でいつでも消せます。
  • Googleへの許可は、画面の「外す」、または Google アカウントの「サードパーティのアクセス」（https://myaccount.google.com/permissions）からいつでも取り消せます。

(6) 限定的使用の要件

IDおそうじによる Google API から受け取った情報の使用と、他のアプリへの移転は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

4. 本サイトについて

本サイトは、現時点でアクセス解析やCookieを利用していません。ホスティングにはGitHub Pagesを、文字の表示にはGoogle Fontsを利用しており、アクセスの際にGitHubやGoogleのサーバーへ接続し、アクセスログが取得される場合があります。

Google User Data (IDおそうじ Gmail edition) — English

Note: The Gmail edition of IDおそうじ is currently in preparation and is not offered. If it is offered, Google user data will be handled as described in this section.

This section describes how IDおそうじ (ID Osouji) handles data received from Google APIs ("Google user data").

  • Data accessed: Only the read-only scope https://www.googleapis.com/auth/gmail.readonly is requested. The app reads the account's email address, the list of message IDs (excluding spam, sent, drafts and chats), selected headers of each message (From, To, Subject, Date, Message-ID, In-Reply-To, Delivered-To, Authentication-Results, List-Unsubscribe, List-Unsubscribe-Post, Precedence) and the short snippet provided by Gmail. It never downloads full message bodies or attachments, and never modifies, deletes, sends or labels any email.
  • Data use: The data is used only to group messages by sender domain, identify online services the user has signed up for, highlight services that sent data-breach notices, and show links to each service's official settings, password-change and account-deletion pages. Aggregated data (service name, domain, recipient address, dates, recent subjects) is used only to display results to the user. Google user data is not used for advertising, credit or lending decisions, or to develop or train AI/ML models.
  • Data sharing: Neither raw nor aggregated/anonymized Google user data is received by A2E Works or shared with, sold or transferred to any third party (including advertisers, data brokers or AI services). The browser communicates only with Google (sign-in and Gmail API).
  • Data protection: All processing happens inside the user's browser. A2E Works operates no server that receives Google user data. The page's Content-Security-Policy blocks all connections except Google sign-in and the Gmail API, and all traffic is encrypted (HTTPS). The access token is kept only in memory and discarded when the page is closed.
  • Retention and deletion: Nothing is stored on any server of ours. The browser stores only the email addresses of added accounts (removable with "外す" / Remove). The free demo does not store analysis results; the paid edition stores aggregated results only in the user's browser and they can be deleted at any time with "すべて消して初期状態に戻す" (Reset all). Users can revoke access at any time with "外す" or at https://myaccount.google.com/permissions.
  • Limited Use: IDおそうじ's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
