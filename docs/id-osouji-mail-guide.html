IDおそうじ メールの読み込み手順

IDおそうじは、メールから「これまでに登録したサービス」を洗い出すツールです。 最初に、お使いのメールを読み込みます。トップの「お使いのメールを選んでください」で、次の2つから選んでください。

お使いのメール 読み込み方 手間
Gmail Thunderbird で受け取ってから読み込む（下の「GmailもThunderbirdにまとめる」）。Googleにログインして直接読み込む版は準備中です 少ない
Thunderbird・Outlook パソコンに保存してあるメールを選ぶ。Gmail・Yahoo!メールなどを Thunderbird で受け取っていれば、ボタン1つで全部まとめてチェック 少ない

Gmailは、Thunderbird に簡単に追加できます（下の「GmailもThunderbirdにまとめる」）。Yahoo!メールなど、Gmail以外のメールは、ご自身で Thunderbird に受け取る設定ができる方が対象です。Thunderbirdで受け取れていれば、そのフォルダを選ぶだけで読み込めます。 おすすめは、Gmailも Thunderbird で受け取っておくことです。 そうすれば「フォルダを選ぶ」ボタン1つで、全部のアドレスのメールをまとめてチェックできます（下の「Thunderbirdにまとめるとできること」）。

どの読み方でも共通のこと

  • パスワードは、IDおそうじには入れません。読みも保存もしません。
  • 結果は、お使いのパソコンのブラウザの中にだけ保存されます。
  • 読み込んだあとは、画面の「進め方」の①〜⑤の順に進めてください。

Gmail

Googleにログインして Gmail を直接読み込む版は、準備中です。

いまは、Gmailを Thunderbird で受け取ってから、下の「Thunderbird・Outlook」の方法で読み込んでください。Gmailの追加は数分で済みます（下の「GmailもThunderbirdにまとめる」）。

Thunderbird・Outlook

すでにThunderbirdやOutlookを使っている方、メールをパソコンに保存している方向けです。 パソコンにあるメールを、より細かくチェックできます。外付けHDDやUSBメモリにある古いメールも、そのまま読み込めます。

Thunderbird

  1. IDおそうじのトップで 「Thunderbird・Outlook」 を押します。
  2. 「フォルダを選ぶ（Thunderbird）」 を押し、プロファイルフォルダ（「（英数字）.default-release」という名前のフォルダ）を選びます。中の ImapMail（IMAPで受け取っているアカウント）と Mail（POPで受け取っているアカウント）を、全部のアカウントまとめて読み込みます。 
    （英数字）.default-release   ← ここを選ぶ
├ ImapMail   … Gmail・Yahoo!メールなど（IMAPで受け取っているアカウント）
│ ├ imap.gmail.com      … 1つ目のアカウント
│ ├ imap.gmail-1.com    … 2つ目のアカウント
│ └ imap.mail.yahoo.co.jp
├ Mail       … POPで受け取っているアカウント・ローカルフォルダ
└ そのほか（設定・RSSなど。自動で外します）
    imap.gmail.com などを1つだけ選ぶと、そのアカウントしか読み込みません。
  3. ブラウザに「このサイトに ○個のファイルをアップロードしますか？」と出たら、「アップロード」を押します（実際にはどこにも送りません）。Thunderbirdはフォルダ1つ（受信トレイなど）を1つのファイルにまとめて保存しているので、ファイルの数はメールの数より少なくて正常です。
  4. 読み込んだあと、「アドレスごとの一覧」に、使っているアドレスが全部出ているか確かめます。

Thunderbirdのメールの場所

  • Thunderbirdのメニュー「ヘルプ」→「トラブルシューティング情報」→「プロファイルフォルダー」の 「フォルダーを開く」 で分かります。
  • Windowsでは、通常は C:\Users\（ユーザー名）\AppData\Roaming\Thunderbird\Profiles\（英数字）.default-release\ の中にあります。
  • 迷惑メール・送信済み・下書き、RSS（ブログとニュース）、設定などのフォルダは、自動で外します。ごみ箱は、消した登録メールが残っていることがあるので読み込みます。

Outlook（パソコンのOutlook）

  1. Outlookを閉じます。 開いたままだと読めないことがあります。
  2. IDおそうじのトップで 「Thunderbird・Outlook」 を押します。
  3. 「ファイルを選ぶ（Outlook・書き出したファイル）」 を押し、データファイル（.pst）を選びます。

データファイル（.pst）の場所

  • Outlookのメニュー「ファイル」→「アカウント設定」→「アカウント設定」→「データファイル」タブで分かります。
  • 通常は ドキュメント\Outlook ファイル の中にあります。

読めないもの

  • Outlook.com や Microsoft 365 のメール（.ost ファイル）は、この版では読めません。

書き出したメールファイル

.mbox や .eml のファイルは、「ファイルを選ぶ」 でそのまま選べます。

Thunderbirdにまとめるとできること

Thunderbird は、無料で使えるパソコン用のメールソフトです。いくつものメールアドレスを登録して、1か所で扱えます。

  • 全部のメールを1つの画面で見られる Gmail・ドコモメールなどのキャリアメール・プロバイダのメール・Yahoo!メール（参考の手順あり）などを、まとめて登録できます。サービスごとにアプリやWebを開き直す必要がなくなります。
  • IDおそうじで、ボタン1つで全部のアドレスを棚卸しできる プロファイルフォルダを選ぶだけで、登録したすべてのアドレスのメールをまとめて読み込みます。各サービスに「どのアドレスで登録したか」も表示されます。
  • 古いメールを手元に残せる（バックアップ） 下の「バックアップのしかた」の一手間をかけると、サービスが終わっても、アドレスを解約しても、メールが残ります。

GmailもThunderbirdにまとめる

Gmailは、Thunderbird に簡単に追加できます。

  1. Thunderbirdのメニュー（右上の ≡）→ 「アカウントを追加」→「メール」 を選びます（古い版では「新規作成」→「既存のメールアカウント」）。
  2. 名前と Gmail のアドレスを入れて「続ける」を押します。
  3. Googleのログイン画面が出るので、ふだんどおりログインし、Thunderbird へのアクセスを許可します。
    • パスワードは Google の画面で入れます。Thunderbird にも IDおそうじにも残りません。
  4. 受信が終わったら、IDおそうじでプロファイルフォルダ（ImapMail と Mail が入っている「（英数字）.default-release」）を選びます。Thunderbirdで受け取っている全部のメールが一緒に読み込まれます。

バックアップのしかた（大事）

Thunderbirdで受け取っただけ（IMAP）では、バックアップになりません。 IMAPは両方が連動するので、Thunderbirdで消すとサーバーからも消え、サーバーで消えると Thunderbird からも消えます。

残しておきたいメールは、次のどれかで「手元だけのコピー」を作ってください。

  • ローカルフォルダにコピーする（いちばん簡単） 左の一覧の「ローカルフォルダ」に新しいフォルダを作り、残したいフォルダのメールを選んで、右クリック →「コピー」でそこへ入れます。ローカルフォルダのメールは、サーバーで消えても残ります。
  • プロファイルフォルダごとコピーする Thunderbirdを閉じてから、プロファイルフォルダ（場所は下の「Thunderbirdのメールの場所」）をまるごと外付けHDDやUSBメモリにコピーします。設定も含めて元に戻せます。
  • mboxとして書き出す 拡張機能「ImportExportTools NG」を入れると、フォルダを .mbox ファイルとして書き出せます。書き出したファイルは、IDおそうじの「ファイルを選ぶ」でそのまま読み込めます。

参考：Yahoo!メールを Thunderbird で受け取る

ご自身で設定できる方向けの参考です。 Yahoo!メールと Thunderbird の設定は、お使いの環境や Yahoo! 側の仕様変更で大きく変わるため、個別のお問い合わせにはお答えできません。 Yahoo! 側の変更で、この方法が使えなくなることもあります。

Yahoo!メールは、ブラウザから直接は読めません（Yahoo! JAPANに、外部からメールを読むための公開の仕組みが無いため）。Thunderbird で受け取れれば、IDおそうじで読み込めます。

1. Yahoo! JAPAN ID の設定

  1. 「登録情報」→「ログインとセキュリティ」で、「ログイン方法によるアクセス制限」を無効にします。
    • 有効のままだと、パスワードでのログインが拒否され、Thunderbird から入れません。
  2. パスワードを使わない設定（SMSや生体認証だけ）にしている場合は、パスワードを設定します。

2. Yahoo!メールで IMAP を有効にする

  1. Yahoo!メールの設定（歯車）→ 「IMAP/POP/SMTPアクセス」 を開きます。
  2. 「Yahoo! JAPAN公式サービス以外からのアクセス」を「許可する」、IMAP・POP・SMTP を「利用する」にして保存します。
  3. うまくつながらないときは、一度ここを「無効」にして保存 → パスワードを変更 → ログアウトしてログインし直す → もう一度「許可する」にして保存、の順でやり直すと通ることがあります。

3. Thunderbird に追加する

  1. Thunderbird を最新版にします（設定 →「一般」→ 更新を確認）。
  2. メニュー（右上の ≡）→ 「アカウントを追加」→「メール」 で、Yahoo!メールのアドレスとパスワードを入れます。
    • 受信サーバーは imap.mail.yahoo.co.jp（ポート993・SSL/TLS）。通常は自動で設定されます。
    • パスワードを入れるのは Thunderbird だけです。IDおそうじには入れません。
  3. 失敗したときは、そのアカウントを削除し、Thunderbird を再起動してから追加し直します。

4. 気をつけること

  • Thunderbirdでメールを消すと、Yahoo!メールからも消えます。 IMAPは両方が連動するためです。
  • 受信が終わったら、IDおそうじの「Thunderbird・Outlook」から、プロファイルフォルダ（「（英数字）.default-release」）を選びます。

うまくいかないとき

  • 「読み込めるメールファイルが見つかりませんでした」と出る 選んだフォルダが違う可能性があります。ImapMail と Mail が入っている「（英数字）.default-release」のフォルダを選び直してみてください。
  • 使っているアカウントの一部が「アドレスごとの一覧」に出ない imap.gmail.com などアカウントのフォルダを1つだけ選んでいる可能性があります。1つ上の ImapMail のさらに上、「（英数字）.default-release」を選び直してください。それでも出ないときは、Thunderbirdでそのアカウントの「設定」→「同期とディスク領域」で「このアカウントのメッセージをこのコンピューターに保存する」にチェックが入っているか確かめてください。
  • Thunderbirdで受け取ったメールが少ししか読み込まれない Thunderbirdの受信が終わっていない可能性があります。Thunderbirdで各フォルダを一度ずつ開き、受信が終わってからもう一度読み込んでください。
